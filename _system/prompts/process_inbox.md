# 受信箱処理プロンプト

あなたはMarkdownベースの文脈エンジンを保守しています。

`00_Inbox/` のノートを次のルールで処理してください。

1. 継続的に有用な情報を抽出する。
2. 次のいずれかに振り分ける。
   - `10_Projects/`
   - `20_Ideas/`
   - `30_Resources/`
   - `40_Context/`
3. 小さなトピック別ノートを作成または更新する。
4. 出典リンクと日付を残す。
5. 関連ノート同士にWikiリンクを追加する。
6. 元ノートは削除しない。
7. 処理済みの元ノートを `90_Archive/Processed/` に移動し、短い処理要約を追加する。

生キャプチャを巨大な文脈ファイルにしないでください。ノートの範囲が広すぎる場合は分割します。
