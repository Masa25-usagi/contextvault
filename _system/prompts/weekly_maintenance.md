# 週次メンテナンスプロンプト

この保管庫の文脈品質を監査してください。

作業内容:

1. 重複ノート、または概念が重なっているノートを見つける。
2. 1,200語を超えるノートを見つけ、分割案を出す。
3. 壊れたWikiリンクを見つける。
4. 古くなったプロジェクトを見つける。
5. 新しい安定した文脈ファイルを索引へ追加すべき場合のみ、`40_Context/MyContext.md` を更新する。
6. ファイルは削除しない。古い生データは、有用な情報を保存した後でのみ `90_Archive/Processed/` に移動する。

返答内容:

- 実施した変更。
- 人間の確認が必要なファイル。
- ユーザーへの質問。
